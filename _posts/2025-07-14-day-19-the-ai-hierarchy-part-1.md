## 📅 Day 19: July 14, 2025

### 📝 Phase 3: "Something About AI" (Pure Concepts)

Today, I started **Phase 3** by learning the **AI Hierarchy**—understanding the "buzzwords" and how AI, Machine Learning, and Deep Learning relate to each other.

### 🧠 Concepts Learned

* **Artificial Intelligence (AI):**
    * **Definition:** The broadest concept. Creating machines that can simulate human intelligence.
    * **Goal:** Make computers "think" or "behave" like humans.
    * **Examples:** Chess-playing computers, virtual assistants (like my Jarvis!), self-driving cars.
    * **Analogy:** AI is the entire "umbrella" concept.

* **Machine Learning (ML):**
    * **Definition:** A *subset* of AI. Teaching computers to learn from data without being explicitly programmed.
    * **Key difference:** Instead of writing rules manually, the machine "discovers" the rules from examples.
    * **Traditional programming:** Input + Rules → Output
    * **Machine Learning:** Input + Output → Rules (learned automatically)
    * **Example:** Instead of writing "if email contains 'free money', mark as spam," ML learns this pattern from thousands of spam examples.
    * **Analogy:** ML is a specific *method* within the AI umbrella.

* **Deep Learning (DL):**
    * **Definition:** A *subset* of ML that uses complex structures called "neural networks."
    * **Key feature:** Can handle very complex problems (image recognition, speech, translation).
    * **Inspired by:** The human brain (networks of neurons).
    * **Examples:** Face recognition, ChatGPT, image generators.
    * **Analogy:** DL is a specialized *technique* within ML.

* **The Visual Hierarchy:**
    ```
    ┌─────────────────────────────────┐
    │   Artificial Intelligence (AI)  │ ← Broadest concept
    │  ┌──────────────────────────┐   │
    │  │  Machine Learning (ML)   │   │ ← Subset of AI
    │  │  ┌───────────────────┐   │   │
    │  │  │ Deep Learning (DL)│   │   │ ← Subset of ML
    │  │  └───────────────────┘   │   │

    └─────────────────────────────────┘
    ```

### ✅ Today's Goal
The goal was to understand the relationship between AI, ML, and DL. These terms are often used interchangeably, but they're not the same—knowing the hierarchy helps me speak intelligently about AI in my viva!
